# iPhone 18 Pro — обзор

Сделал этот сайт для своего портфолио. Хотелось собрать страницу в духе продуктовых страниц Apple: минимум текста, чёрный фон и 3D-модель телефона, которая реагирует на прокрутку.

**Посмотреть:** https://azer1xxx1337.github.io/iphone/

## Что тут есть

- 3D-модель телефона справа (на мобилке сверху). Когда листаешь разделы, она поворачивается: в «Камере» показывает заднюю панель, в «Корпусе» встаёт боком и т.д.
- Можно поменять цвет корпуса — чёрный, бургунди, голубой, серебристый.
- На экране модели нарисован экран блокировки с настоящим текущим временем и датой, обои подстраиваются под выбранный цвет.
- На компе модель можно покрутить мышкой.
- Разделы: экран, камера, производительность, батарея, корпус, сравнение с 17 Pro, характеристики и итог.
- Нормально смотрится и на телефоне.

## Как сделано

Обычный HTML, CSS и JavaScript, без фреймворков и сборки. Для 3D использовал Three.js (r128) и GLTFLoader. Экран блокировки рисуется на canvas и накладывается на экран модели как текстура, поэтому время всегда актуальное.

Модель лежит в `model.js` в виде base64 — так проще, чем возиться с отдельным `.glb` файлом.

Характеристики брал из обзоров IT Pro, Forbes, PhoneArena и MacRumors, ссылки есть внизу страницы.

## Запустить у себя

Скачать репозиторий и открыть `index.html`. Или через локальный сервер:

```
python3 -m http.server 8000
```

и зайти на http://localhost:8000
